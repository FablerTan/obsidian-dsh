# 0040 范围卡片标题去掉与徽标重复的 @ /

> 对应路线图 [R-23](../roadmap.md#需求待办)。后续需求：0039 给卡片加了 @ / 字符徽标，标题里的「@」「/」变得冗余，用户要求去掉。

## 1. 背景与问题

0039 把范围设置收进卡片后，卡片头是：徽标（@ 或 /）+ 标题（「@」引用范围 / 「/」技能范围）+ 模式下拉。徽标已经把范围标出来了，标题里的「@」「/」重复一遍，读起来还多一层书名号，视觉上很吵。

## 2. 目标与非目标

- 目标：两个卡片的标题改成 **「引用范围」** 与 **「技能范围」**；徽标保持 @ 或 / 不变；下拉、说明、卡身内容与行为全部不变。
- 非目标：不改设置项、匹配语义、名单数据、卡片样式；不动其他设置模块的文案。

## 3. 实现路径调研（≥ 2 条）

| 路径 | 做法 | 改动面 | 代价与风险 | 结论 |
|---|---|---|---|---|
| **A（本次落地）** | 只改 renderMentionScope / renderSkillScope 传给 renderScopeCard() 的 title：「「@」引用范围」改成「引用范围」、「「/」技能范围」改成「技能范围」；徽标与其余不变 | settings/sections/chat.ts 两处字符串 | 最小改动；唯一风险是下拉的 aria-label 跟着变短，补成「引用范围模式 / 技能范围模式」 | **推荐** |
| B | 去掉书名号但保留字符：「@ 引用范围」「/ 技能范围」 | 同上 | 与徽标仍重复，用户明确说「前面加了 @ 和 / 就去掉」 | 不推荐 |
| C | 徽标换成图形图标（如 at-sign / 斜杠 SVG），标题保留「引用范围」 | 同 A + 图标资源 | 字符徽标与标题等宽对齐已经调好，换图标收益低 | 不推荐 |

**推荐 A**：直接把冗余字符从标题里去掉，徽标继续承担归属标识。

## 4. 改动清单

| 文件 | 改动 |
|---|---|

## 5. 行为变化

- 卡片标题分别显示「引用范围」「技能范围」（徽标仍是 @ 或 /）；其他一切不变。

## 6. 风险与回滚

| 风险 | 影响 | 回滚方式 |
|---|---|---|
| 标题变短后，仅看文字无法区分两个卡片 | 徽标与说明仍在，可区分 | 恢复标题里的字符即可 |
