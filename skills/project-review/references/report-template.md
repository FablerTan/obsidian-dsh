## 7. 建议重构批次

### 7.1 批次汇总

顺序固定：**文档同步 → 死码清理 → 纯搬运拆分 → 收敛重复**；每批结束 `npm run build` + `npm run check`，一批一提交。

| 批次 | 内容 | 涉及文件 | 依赖前置 | 风险 | 验证 |
|---|---|---|---|---|---|
| 1 文档同步 | 修断链与过期事实 | `docs/<待改文档>.md` | 无 | 低 | `npm run check` |
| 2 死码清理 | 删无调用方导出 | `src/<死码所在文件>` | 批次 1 | 低 | 构建 + `grep` 无输出 |
| 3 纯搬运拆分 | 拆超长文件 | `src/view/native/ui/<拆分文件>.tsx` | 批次 2 | 中 | 构建 + 手动回归涉及面 |
| 4 收敛重复 | 合并等价实现 | `src/shared/<收敛目标>.ts` | 批次 3 | 中 | 构建 + 手动回归 |

### 7.2 需要你拍板

| 选项 | 范围 | 工作量 | 风险 | 说明 |
|---|---|---|---|---|
| A（推荐） | 只做批次 1~2 | 小 | 低 | 零行为风险，先清死码与文档 |
| B | 批次 1~3 | 中 | 中 | 多一次大 diff，需要手动回归 |
| C | 全部（1~4） | 大 | 中 | 收敛重复要证明等价，回归面最大 |

- [ ] 选哪一项（默认推荐 A；选别的请说明）
- [ ] 是否需要把审阅结论立项为 `R-<n>` + 提案（≥ 2 条路径）
- [ ] 其它取舍（例如某条只记录不动）

### 7.3 验收标准（可判定）

把「怎样算做完」写成命令与期望输出，不要写「应该没问题」：

| 验收项 | 命令 | 期望 |
|---|---|---|
| 死码清干净 | `grep -rn "<符号>" src` | 无输出 |
| 超长文件收敛 | `wc -l src/view/native/ui/*.tsx` | 无 > 300 行（例外需在本文件说明） |
| 构建与检查 | `npm run build` / `npm run check` | 通过，`main.js` 为最新构建 |
| 行为不变 | `docs/development.md`「现状与手动回归」相关项 | 逐条通过 |
